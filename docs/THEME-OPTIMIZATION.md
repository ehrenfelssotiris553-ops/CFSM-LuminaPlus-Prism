# 主题优化（1.2.21+ipstack.4）

本版只改主题，不改 CF 后端、D1 结构或探针。基于 ipstack.3 的用户反馈与复查。

## 显示规则

- 卡片页只控制顶部 V4/V6 标签。
- 延迟页独立控制全站 V4/V6 默认、每台 VPS 的协议组和每条线路。
- 优先级：单条显示/隐藏 > 本台协议组显示/隐藏 > 全站协议默认；“自动”表示跟随上一级。
- 每条固定后端 task ID 保存明确协议：IPv4、IPv6、其他。其他不受 V4/V6 组开关影响。
- 升级第一次从旧名称推断一次协议，同时复制旧标签开关对延迟的影响以保留原显示；管理员首次打开自动保存一次，后续改名称不会改变协议归属。请在协议归属中确认无法由旧名判断的“其他”。
- 旧浏览器本机的协议隐藏也做一次迁移，不复制未修改的站点默认值；新的标签操作会标记为新规则，避免重新联动。
- 线路显示结果会明确标记“显示、隐藏、未选入首页多线路”。未选入时有“加入全站首页多线路”入口，该操作会改变全站多线路列表；单台已换线替代的任务可在该 VPS 恢复。
- 隐藏不停止检测、不删除历史。首页卡片不显示；详情页的延迟图默认也不画（开着首页多线路时，详情页只画这台在首页显示的那几条，没选进首页的也不画，顺序和首页一致），图例末尾有「设置里隐藏了 N 条 · 显示」可以临时放出来（不改设置）；卡片上的换线路菜单也不列这台隐藏的线路。迷你和列表仍使用其单线路任务；大卡片/小卡片支持多线路。

## 手机操作

按 VPS 折叠，只展开需要配置的服务器；搜索名称、UUID、分组和地区可自动展开匹配项。协议归属另放全站折叠区。小屏保存状态换行展示，避免横滑后才能看到状态。隐藏行在创建图表桶之前过滤，减少不必要的计算。

## 保存冲突

用户开始编辑时保留基线，保存时与本页缓存的站点配置做字段级三方比较。不同节点/任务的改动合并；
同一字段出现不同远端更改时暂停自动保存，保留本机修改。刷新后基线与修改仍保留。

冲突时可选：采用后端配置（不写入）或保留我的修改并保存。协议归属和协议组也使用稀疏本机修改，未编辑的字段不锁在本地。

**保存前什么时候重拉 `/api/config`**：本页缓存不到 5 分钟就直接当底（后端主题规范：`/api/config` 整个页面只查一次）；
超过 5 分钟（页面开了很久）第一次保存前先重拉一次，冲突检查据此看到别的设备的改动，旧副本不会盖掉它们。
原版每次保存都重拉；ipstack.5 一度完全不重拉，又出现了原版 v1.2.19 修过的「旧页面盖掉新设置」，最后取了这个折中。

**边界：后端整对象保存接口没有版本条件写入，前端无法保证真正同时写入时的原子保护。** 没有新增首页配置轮询。

## 时钟异常

超过当前时间一分钟的未来时间不能作为在线证据，仍可使用正常的接收时间。未来样本有明确提示；时间校正后不因旧的未来样本而拒收新帧或采用旧快照指标。没有缩短后端五分钟离线阈值，也不修复后端已写入的错误历史时间。
