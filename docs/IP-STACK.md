# IPv4 / IPv6 独立显示定制版

基于原版 [CFSM-Theme-LuminaPlus](https://github.com/volcano-1025/CFSM-Theme-LuminaPlus) v1.2.21 的定制版，
当前版本见 [CHANGELOG.md](../CHANGELOG.md)。只改主题，不改 CF 后端、D1 结构或探针。

## 功能一览

| 位置 | 功能 |
| --- | --- |
| 首页卡片（四种视图） | V4 / V6 标签，V4 绿色、V6 蓝色；悬停和读屏有完整说明 |
| 首页控件栏 | 按协议筛选：全部 / 双栈 / 仅 V4 / 仅 V6，按钮带当前分组、地区下的数量 |
| 首页总览 | 「在线节点」卡显示双栈 / 仅 V4 / 仅 V6 各有几台 |
| 详情页 | 系统信息里的「网络协议」显示 V4 / V6 标签，规则与首页一致 |
| 浏览器标签页 | 有节点离线时标题变成「(N 离线) 站点名」 |
| 浏览器通知 | 节点掉线 / 恢复时弹通知（可选，只存本机） |
| 首页延迟 | 按协议、按节点、按单条线路控制首页显示哪些延迟线路，见 [THEME-OPTIMIZATION.md](THEME-OPTIMIZATION.md) |
| 首页 CF 用量（站长） | 今天 / 昨天的 D1 读写、Workers、DO 请求，对比免费版每日额度 |
| Agent 更新提醒（站长） | 首页提示哪几台 Agent 比最新版旧，可以「忽略此版本」；详情页显示 Agent 版本并标出「可更新」 |
| 截图打码 | 选几台机器，把名称、地区国旗、标签分组、价格到期（以及总览资产）换成假内容再模糊，方便截图分享；只在本机 |

除 CF 用量外都不增加任何后端请求，只使用 `/api/config`、`/api/servers` 与实时推送里已有的数据。

## 设置在哪里

**主题设置 → 卡片 → V4 / V6 标签与协议筛选**

- 「默认显示 V4 标签」「默认显示 V6 标签」：控制处于自动模式的节点。
- 「首页按协议筛选」「总览显示协议统计」：两个首页功能的开关，默认打开。
  全站只有一种协议时（比如全是双栈）筛选栏不显示。
- **按分组批量设置**：选一个分组（或全部 VPS）和要改的协议，一次应用到组里所有节点。
- **每台 VPS 单独设置**：默认只列出已单独设置的节点，搜索名称 / ID / 分组 / 地区，或点「显示全部」。
  每台一行，IPv4、IPv6 各一组「自动 / 显示 / 隐藏」按钮，旁边直接显示首页最终效果。
  「全部恢复自动」会先确认。

| 单台选项 | 作用 |
| --- | --- |
| 自动 | 对应全局开关开启，并且后端上报对应标记时，才显示标签。 |
| 显示 | 为这台 VPS 固定显示该标签，可覆盖全局关闭和后端标记缺失。 |
| 隐藏 | 为这台 VPS 固定隐藏该标签，不影响另一种协议。 |

「显示」是人工标签，不代表经过新的连通性检测，不显示真实 IP。标签与延迟线路分开设置，修改标签不会改变延迟线路。

**首页筛选和统计的口径**：单台设了「显示 / 隐藏」以它为准，自动时看后端标记；
**不受**「默认显示 V4 / V6 标签」开关影响 —— 那两个开关只决定标签画不画，不代表节点没有这种协议。

**主题设置 → 外观 → 浏览器提醒**

- 「标题显示离线数量」：站点设置，管理员保存后对所有访客生效，默认打开。
- 「节点掉线时发送浏览器通知」：**只存在当前设备的当前浏览器里**，打开时会向浏览器申请通知权限。

两者都只在首页或详情页开着、且页面在前台（没切到别的标签页、没最小化）时有效：
后端主题规范要求页面进入后台就断开实时连接，后台期间收不到数据，也就判断不了掉线。
**不建议为了收通知把页面一直开着**：只要有页面连着实时推送，探针就让所有 Agent 改成约 2 秒上报一次
（没人看时约 60 秒一次），一直开着会明显多耗 CF 额度（WSS 上报的节点，一台全天约多 2000 次 DO 请求）。
要 24 小时掉线提醒，用后台自带的 Telegram / Webhook 通知：它在服务端判断，不用开着页面，也不影响上报频率。
浏览器通知适合「正开着看的时候顺便提醒一下」。后台「前端实时连接超时」可以给一直开着的页面设个上限。

**主题设置 → 外观 → 截图打码**（也可以直接点首页快捷栏的「截图打码」按钮）

- 打开后首页底部出现「点卡片选择要打码的机器」，点卡片打勾或取消（列表视图点整行），点「完成」结束选择。
  打码会一直保持（刷新页面也在），再点一次快捷栏按钮关闭。设置页里也能直接勾选机器、全选。
- 「打码哪些内容」：名称 / 地区与国旗 / 标签与分组 / 价格与到期 / 总览资产，默认全部。
  「总览资产」只看这一项，和选了哪些机器无关；打开后总览的资产金额和评级都遮住。
- 打码的机器在首页四种视图、详情页标题和机器切换列表、续费提醒、资产页、流量页都显示假内容。
- 做法：先把文字换成同样长度的假字符（金额统一换成 xx，看不出位数），再加模糊。截图里还原不出来，
  鼠标悬停提示和读屏里也没有真实内容。国旗换成一块灰色色块。
- **只存在当前设备的当前浏览器里**：不改站点设置、不发请求，别人打开网站看到的是原样。
- 没遮住的：地区栏每个地区的台数、卡片排序位置可能透露一点信息；延迟线路名（电信 / 联通 / 移动）不打码。
- 快捷栏不想要这个按钮：主题设置 → 外观 → 快捷栏 → 「截图打码」。

**主题设置 → 首页 → 站长专属信息**（只有登录后才显示这一组）

- 「首页显示 CF 用量」：默认打开。Lumina Prism 里 CF 用量和 Agent 更新提醒收在总览下面的**「站长」条**里，
  只有登录站长看得到。站长条默认收起成一行（电脑和手机都是），显示今天用得最多的那一项和「N 台可更新」，
  点一下展开看完整的用量和提醒；展开还是收起记在这台设备上。两样都没有时整条不显示。
- 「用量刷新方式」：
  - **打开首页时**（默认）：每次打开或刷新（F5）首页查一次；从详情页返回、切回这个标签页都不重查。
  - **只手动**：打开首页不查，点卡片右上角的刷新按钮才查。
  - **定时**：每 5 / 10 / 30 / 60 分钟查一次；页面在后台时暂停，切回来如果已经超过间隔就补查一次。
  - 不管哪种，卡片上随时可以手动刷新。
- 「Agent 更新提醒」：默认打开。最新版本号由后端 `/api/config` 只发给登录站长；节点没上报版本、或版本号认不出时不提示。
  想晚点升级就点提醒条上的「忽略此版本」：这一版不再提醒，Agent 出了更新的版本会再提醒；这个选择同步到后端，
  换台设备也一样。设置里会显示「已忽略 vX」，点「恢复提醒」撤回。

关于 CF 用量：

- 数据和后台「查询 CF 用量」按钮是**同一个请求**（`POST /admin/api`，`action: d1_usage`），后端用你在后台保存的
  CF Token / Account ID 去查 Cloudflare 统计接口，Token 不经过浏览器。查一次是 1 次 Workers 请求，不耗 D1 额度。
- 「今天」按 UTC 计算，北京时间每天 08:00 清零；Cloudflare 的统计有几分钟延迟。百分比对比的是免费版每日额度
  （D1 读 500 万行、写 10 万行，Workers 10 万次，DO 10 万次），付费版的额度不一样。
- DO 请求是后端按计费规则估算的（HTTP 请求 + 休眠唤醒 + 收到的 WebSocket 消息每 20 条算 1 次），鼠标放上去能看到明细。
- **这是本定制版唯一偏离后端主题规范的地方**：规范不允许主题调用 `/admin/api`。所以只给登录站长、可以关、默认一次打开只查一次。
  探针升级后如果后台接口变了，卡片会显示「接口有变化，暂时查不了」，主题其他部分不受影响。
- 后台没填 Token 或 Account ID 时，卡片提示去后台设置。

登录管理员的设置自动保存到后端 `theme_options`；未登录访客的修改只留在自己的浏览器。

## 安装与更新

源码在 `main` 分支，推送后由 GitHub Actions 构建并发布到 `dist` 分支。在 CF 监控后台的自定义主题 URL 填：

```text
https://github.com/ehrenfelssotiris553-ops/CFSM-LuminaPlus-Prism/tree/dist
```

- 填 `tree/dist`：Workers 对分支地址缓存约一小时，过了缓存自动是新版。
- 想锁定某一版：把 `dist` 换成那一版产物提交的 40 位 SHA（`dist` 分支的提交记录里可以看到）。

登录后台后，本仓库发新版时页脚「Lumina Prism」后面会出现「新版 vX」。版本检查查的是本仓库的 `dist`，
不会提示原版或 IPStack 版的新版本。原版和 IPStack 版更新的合并方法见 [README](../README.md) 的「同步原版和 IPStack 版」。

## 配置格式

下例的 `节点ID` 是 API 返回的 ID，不是 VPS 名称，也不一定是 IP。可以完全通过界面操作，无需手写 JSON。

```json
{
  "showIpv4": true,
  "showIpv6": true,
  "homepageIpStackOverrides": {
    "节点ID-A": { "ipv4": false, "ipv6": true },
    "节点ID-B": { "ipv6": false }
  },
  "showIpStackFilter": true,
  "showIpStackStats": true,
  "showOfflineCountInTitle": true,
  "showCfUsage": true,
  "cfUsageRefreshMode": "open",
  "cfUsageRefreshMinutes": 10,
  "showAgentUpdateHint": true,
  "agentUpdateIgnoredVersion": ""
}
```

`homepageIpStackOverrides` 里省略某个协议表示自动；`true` 固定显示；`false` 固定隐藏。开关省略时默认打开。
`cfUsageRefreshMode` 可填 `open`（打开首页时）、`manual`（只手动）、`interval`（定时）；
`cfUsageRefreshMinutes` 只认 5、10、30、60，其他值按 10 处理。
`agentUpdateIgnoredVersion` 是点「忽略此版本」时记下的版本号，空串表示没忽略。
浏览器通知开关不在这里，存在浏览器本地的 `cfsm-luminaplus:offline-notify`。

## 回退

在后台把主题 URL 换回原版或之前锁定的 SHA 即可。新增的配置字段只影响本定制版，不会更改服务器网络或删除历史数据；
换回原版会失去本定制版的设置界面和效果。
